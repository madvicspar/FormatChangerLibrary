# format changer

Система для автоматической проверки и исправления оформления документов Word (DOCX) по заданным шаблонам.

## Возможности системы

- Автоматическое определение типов абзацев (заголовки, списки, таблицы и др.)
- Ручное исправление структуры документа*
- Автоматические исправление и проверка форматирования документов
- Использование пользовательских шаблонов форматирования
- Загрузка и экспорт DOCX-документов
- Генерация:
  - исправленного документа
  - документа с комментариями о недочетах форматирования Word
  - документа со списков недочетов
- Интеграции:
  - Telegram (экспорт результатов, авторизация)
  - Email (уведомления, экспорт)


*: Пользователь может исправить результаты автоматического определения типов абзацев

## Технологии

- C#
- HTML, CSS, JavaScript
- ASP.NET Core (MVC)
- Razor Pages
- Entity Framework + PostgreSQL
- OpenXML SDK
- Telegram Bot API
- SMTP (почта)

## Архитектура

- Клиентская часть:
  - загрузка/отображение документа
  - настройка параметров проверки и исправления
  - редактирование структуры документов
- Серверная часть:
  - обработка и анализ документа
  - классификация абзацев
  - генерация результатов
- База данных: PostgreSQL
- Файловое хранилище

## Почему это важно?

Студенты и проверяющие (в том числе преподаватели) зачастую тратят много времени и сил на проверку и исправление форматирование документов. `format changer` автоматизирует этот процесс и позволяет:

- Сократить время на проверку и исправление
- Повысить точность соответствия ГОСТам и прочим требованиям
- Поддерживать единую структуру оформления

Система может быть применима также и работниками организаций, школьниками, писателями и вообще всеми категориями пользователей, которые сталкиваются с форматированием документов.
